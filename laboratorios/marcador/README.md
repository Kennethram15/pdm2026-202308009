## ¿Qué hace setState?

setState básicamente le dice a flutter que en la aplicación hubieron cambios en los estados entonces tiene que actualizarlos para mostrar lo nuevo. Aquí como tal se usa para los marcadores y cuando indica quién va ganando. Si no se usa el setstate, los valores cambian adentro de la aplicación pero no se muestra nada de un cambio visual.
